# Dev Notes - 2026.08

## 2026-08-15

### AGENTS.md와 CONTRIBUTING.md 차이

질문:
- `AGENTS.md`와 `CONTRIBUTING.md`는 어떤 차이가 있고, Codex와 협업할 때 어떤 문서를 쓰는 게 좋은가?

정리:
- `AGENTS.md`는 AI 작업자가 이 저장소에서 작업할 때 참고하는 실무 지침에 가깝다.
- 커밋 규칙, 검증 명령, 배포 절차, 건드리면 안 되는 파일처럼 Codex가 반복해서 따라야 하는 규칙을 짧게 두기 좋다.
- `CONTRIBUTING.md`는 사람 개발자나 오픈소스 기여자를 위한 공식 기여 문서에 가깝다.
- 1인 개발이고 Codex와 자주 협업한다면, 우선 루트 `AGENTS.md`에 짧은 규칙을 두는 방식이 실용적이다.
- 커밋 규칙을 강제로 막고 싶어지면 나중에 `commitlint` 같은 자동화 도구를 추가할 수 있다.

- Conventional Commits를 자동으로 검사하는 `commitlint`와 `husky`의 역할
